Analista de dados

Trabalho com aquisição: o caminho que vai do gasto em mídia até o lead qualificado. Na prática, isso quer dizer construir e operar a camada que sustenta essa leitura, e não só consultá-la.

Ligo as fontes, resolvo as divergências entre elas, defino o que cada métrica significa e opero isso todo dia, com a equipe inteira em cima. Gosto justamente do problema que ninguém vê: quando duas ferramentas contam a mesma coisa de jeitos diferentes, alguém precisa decidir qual número é o número e sustentar a decisão.

Painel, para mim, é veículo. O que interessa é a decisão que sai dele.

  • Pipeline de dados
  • Integração de API
  • Modelagem de métrica
  • Padronização de UTM
  • Auditoria de base
  • Análise para decisão
